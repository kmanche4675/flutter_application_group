## 📌 What You Need

Before running the app, you need to install a few things:

1. **Install Flutter** 🛠️  
   - Go to [Flutter's official website](https://flutter.dev/docs/get-started/install)  
   - Download and install Flutter for your operating system

2. **Install Visual Studio Code (VS Code)** 🖥️  
   - Download it from [VS Code's official website](https://code.visualstudio.com/)
   - Install it like any other software

3. **Install Flutter & Dart Plugins in VS Code** 🎨  
   - Open VS Code
   - Click on **Extensions** (it's the square icon on the left bar)
   - Search for **Flutter** and install it
   - It will automatically install the Dart plugin too!

4. **Set Up an Emulator or Connect a Phone** 📱  
   - If using an Android phone: 
     - Enable **Developer Mode** & **USB Debugging** in your phone’s settings
     - Connect it to your computer using a USB cable
   - If using an emulator: 
     - Open **Android Studio** (install it from [here](https://developer.android.com/studio) if you don’t have it)
     - Create a new virtual device and start it

## 🚀 How to Run the App

1. **Download the Project** 📥  
   - Click the green **Code** button on GitHub
   - Select **Download ZIP**
   - Unzip the file to a folder on your computer

2. **Open the Project in VS Code** 🏗️  
   - Open **VS Code**
   - Click **File > Open Folder**
   - Select the folder where you unzipped the project

3. **Install Dependencies** 📦  
   - Open the terminal in VS Code (**View > Terminal**)
   - Run this command:
     ```sh
     flutter pub get
     ```

4. **Run the App** ▶️  
   - Make sure your emulator or phone is connected
   - In the terminal, type:
     ```sh
     flutter run
     ```
   - Wait a few seconds, and BOOM! 🎉 Your app should be running!

## 🛠 Troubleshooting (If Things Go Wrong)

- **Flutter command not found?**  
  - Restart your computer and try again

- **Device not found?**  
  - Check if your phone is connected or if your emulator is running

- **Other errors?**  
  - Run this command in the terminal:  
    ```sh
    flutter doctor
    ```
  - It will tell you what’s missing and how to fix it
